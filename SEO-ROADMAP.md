# SEO-роадмап art-vision.online

> Составлено на реальных данных: Яндекс Wordstat (спрос), Яндекс Search API (выдача/конкуренты), Яндекс Вебмастер (текущие позиции), Яндекс Метрика (трафик). Регион спроса — Россия (225), broad match, показов/мес.

## 0. Отправная точка (факт)

- **Вебмастер:** поисковых запросов у сайта **нет** (история не накоплена).
- **Метрика:** ~2 визита за июнь, источник — прямой заход.
- **Вывод:** сайт greenfield — оптимизировать «существующие позиции» нечего. Задача — **построить топикальные страницы под доказанный спрос и добиться индексации**, а не докручивать рейтинги.

## 1. Семантическое ядро: головные запросы

| Запрос | Спрос/мес | Кто должен владеть |
|--------|-----------|--------------------|
| заказать сайт | **92 734** | Главная + сквозные CTA |
| разработка сайта | **29 330** | Главная / «Разработка сайтов» |
| создание сайта под ключ | 1 593 | Главная (вторичный) |
| разработка интернет-магазина | 1 231 | /services/ecommerce-development |
| корпоративный сайт разработка | 236 | /services/corporate-website |
| разработка сайта на **next js** | **7** | ❌ не таргетировать — спроса нет |

**Правило:** клиент ищет по намерению («заказать / разработка сайта»), а **не по стеку** («next.js»). Next.js — аргумент внутри страницы (скорость, SEO), но не цель ранжирования.

## 2. Нишевые решения: спрос vs текущие страницы

| Ниша (целевой B2B-запрос) | Спрос | Страница на сайте | Действие |
|---------------------------|-------|-------------------|----------|
| сайт для автосервиса | 979 | `/solutions/auto-services` ✅ | оптимизировать, усилить |
| сайт для стоматологии | 797 | `beauty-health` (частично) | вынести в отдельную мед-страницу |
| сайт производителя окон | 526 | `windows-construction` | вынести «окна» в lead тайтла/H1 |
| сайт для салона красоты | 489 | `/solutions/beauty-health` ✅ | ок |
| сайт кухни на заказ | 332 | `furniture-kitchens` | lead = «кухни на заказ», не «мебельная компания» (10) |
| сайт для строительной компании | 177 | `windows-construction` | ок |
| сайт для транспортной компании | 154 | `/solutions/logistics-transport` ✅ | ок |

**Мис-таргетинг по формулировкам (важно):**
- «сайт для мебельной компании» = **10**, но «сайт кухни на заказ» = **332** → меняем ведущую формулировку, не нишу.
- «сайт для оконной компании» = **3**, но «сайт производителя окон» = **526** → то же.

## 3. Незанятые ниши с сильным спросом (новые страницы)

| Ниша | Спрос | Обоснование |
|------|-------|-------------|
| **сайт для ресторана** | **1 656** | страницы нет — чистая упущенная выгода |
| **сайт юридической компании** | **1 549** | `services-training` покрывает частично → нужна отдельная страница |
| сайт для юриста | 1 166 | синоним выше, тот же кластер |
| **сайт для клиники** | **1 146** | у студии есть кейс `dental-clinic-msk` — сильный козырь |

| сайт для фитнес-клуба | 89 | низкий приоритет |

⚠️ **Проверка интента (по методике Wordstat):** «сайт медицинского центра» = 64 372, но это во многом **навигационный** спрос («найти сайт конкретного медцентра»), а не «заказать разработку». Целевой B2B-запрос здесь — «сайт для клиники» (1 146) / «разработка сайта для клиники». Не гнаться за большой цифрой без проверки намерения.

## 4. Конкурентная выдача (Search API)

**«сайт для автосервиса под ключ»:** reg.ru, Aspro, matronet (конструкторы/шаблоны) + агентства (art6.ru, t4ka.ru).
→ В топе много шаблонных конструкторов. **Дифференциация art-vision** — кастомная разработка, скорость, реальные кейсы. Бить на «не шаблон, а под ваш бизнес».

**«разработка сайта для клиники»:** medico-marketing, solveon, do-seo, Belberry — профильные мед-маркетинг агентства.
→ Ниша занята специалистами. **Козырь art-vision** — кейс `dental-clinic-msk` с цифрами. Без отраслевого кейса в топ не зайти.

## 5. План действий по приоритету

### 🔴 Сделать в первую очередь
1. **Главная** — таргет «разработка сайтов под ключ / заказать сайт». _(уже сделано: canonical, title, description)_
2. **Исправить слаг↔контент** `/services/nextjs-development/` → контент «Мобильная Адаптация». URL `nextjs-development` нерелевантен. Переименовать слаг в `mobile-adaptation` (сайт новый, потерь индексации нет) + 301 со старого.
3. **Перенастроить ведущие формулировки** на страницах `furniture-kitchens` (→ «кухни на заказ») и `windows-construction` (→ «производитель окон» в title/H1/description).

### 🟡 Следующий спринт — новые посадочные (через `data/solutions.js` + `[slug]`)
4. **`/solutions/restaurant`** — «Сайт для ресторана и кафе» (спрос 1 656).
5. **`/solutions/medical-clinic`** — «Сайт для клиники и медцентра» (1 146) + привязать кейс `dental-clinic-msk`.
6. **`/solutions/legal`** — «Сайт для юридической компании» (1 549).
   _Каждая новая ниша = запись в `data/solutions.js` → автоматически попадает в sitemap и получает SEO-метаданные через `generateMetadata`._

### 🟢 Поддержка
7. После деплоя — отправить страницы на переобход в Вебмастере (скилл `yandex-webmaster recrawl`) и следить за индексацией/первыми запросами.
8. Под каждую новую страницу — собрать микро-семантику Wordstat (подзапросы) и закрыть их в H2/FAQ.

## 6. Ожидаемый эффект
- Закрытие 3 новых ниш = +~4 350 показов/мес потенциального целевого спроса, который сейчас полностью утекает к конкурентам.
- Исправление мис-таргетинга (мебель/окна) = оживление 2 уже существующих страниц (с ~13 до ~860 релевантного спроса).
